<h1 align="center">GitOrbit</h1>

## What is GitOrbit?

GitOrbit is a Git management extension for VS Code. It provides Git operations alongside optional AI features for commit messages and code analysis.

## AI Features (Beta)

Optional **[Kuulto AI](https://kuulto.app)** integration for:

- Discussing code changes and commits
- Generating commit messages
- Analyzing code changes

## Features

- Interactive rebase manager
- Commit message generation
- Git Flow support
- Blame view (inline and file-based)
- Git graph visualization
- Tags and contributors view
- Branch diff comparison

## Settings

Configure via VS Code settings:

- `gitorbit.blame.inline.enabled`: Inline blame text
- `gitorbit.blame.gutter.enabled`: Gutter blame heatmap
- `gitorbit.blame.file.enabled`: File blame view
- `gitorbit.sync.autoSyncInterval`: Auto-fetch interval (minutes)
